# Documentación de referencia

**Esta carpeta está en `.gitignore` y no se publica.**

Aquí van los PDF y HTML de documentación de software comercial usados como
guía de interfaz y de formulación, además de artículos científicos.

## Por qué no se versiona

Dos razones, y ambas bastan por sí solas:

1. **Copyright.** Es material de terceros. Redistribuirlo en un
   repositorio público AGPL sería una infracción, por muy libre que sea el
   código propio.
2. **Higiene del proyecto.** Son cientos de megabytes que nadie que clone
   el repositorio necesita para compilar ni para contribuir.

## Regla para el agente

Puede **leerse** para entender qué hace una función o cómo debería
comportarse la interfaz. **El código no puede contener ninguna referencia
a esos productos ni a sus marcas**, ni copiar su texto. Las fórmulas se
citan por su fuente científica original.

Está escrito también en `AGENTS.md`, que es donde el agente lo lee.
